# WaveDrom Web Editor (index.html)

[简体中文](./EDITOR.md) | **English**

A single-file HTML app (~300+ KB, zero build, works offline): click and drag to edit WaveDrom timing diagrams, with the official engine rendering live on the right and WaveJSON generated in sync on the left. Compatible with most common WaveDrom syntax.

![Screenshot](./images/wavedrom-gui.png)

## Usage

Open `index.html` directly in a browser (works over `file://`, no server needed). You can also use the [demo site](https://wave.rtlyes.cn/) — it runs on free hosting, so availability is not guaranteed.

## UI language

A **globe button** sits to the left of "Settings" in the top bar: the UI **follows the system language** by default (Chinese system → Chinese, otherwise English), and you can also pick "Follow system / 简体中文 / English" manually; the choice persists. The bilingual UI covers the top-bar menus, the sidebar panel, the editor toolbar, every option in the Settings menu, all popups (Chart / Edges / cell state panel / Paste / Shortcuts / About), brush names, the empty state and the main operation toasts. Your document (auto-saved content) is independent of the UI language.

## Editing

- **Cycle count**: the `-4 - + +4` buttons in the toolbar above the editor remove 4 / 1 cycles and add 1 / 4 cycles.
- **Point and click**: with the select tool, click any cell to open the state panel (20 waveform states + data label + node mark). **The current state is highlighted** and the title shows it in sync (e.g. "Now: Data · yellow (3)"). The collapse button at the right of the title folds/unfolds the state glyph grid (the folded state is remembered when you reopen the panel).
- **Scroll to cycle**: **scroll the wheel over a cell** to change its state and render immediately — **outside auto mode you don't need to select it first**, just hover any cell and scroll (if a cell is selected and the panel is open, scrolling applies to that cell only and the panel follows). **In auto mode** scrolling changes the locked cell in place without advancing (the panel follows if open). Candidate states are chosen by lane type: **clock** lanes (containing `p n P N`) cycle only through `p n P N`; **bus** lanes (containing `= 2–9`) cycle through `= 2–9 x z`; **signal** lanes (containing `0 1 h l H L u d U D`) cycle through `0 1 h l H L u d U D z x`. A lane whose **first cell is the only one set** is treated as "to be initialized" and cycles through the union of all three sets (25 items, gap excluded), so one cell can set the tone of the whole lane. A lane with no clock and no level/edge characters — only `x`/`z` and the like — falls back to **non-clock**, cycling the union of signal and bus (21 items). Both ends wrap around, and continuous scrolling merges into a single undo step.
- **Brushes**: pick a brush and click or drag across cells to paint. The "data" and digit brushes (2–9, official per-box colors) pull out a wide box when dragged; the "." brush holds the previous cycle's state (after a clock it keeps clocking). The brush bar folds through five layouts: bottom bar (all brushes laid out) ⇄ compact bar (plain text, group flyouts on hover/click, auto-hide on leave or pick) ⇄ corner button (hover/click to open the panel, auto-hide) ⇄ right column (narrow side rail, groups stacked, same flyouts) ⇄ full right panel (1–5 columns, vertical first). In Settings, "Bar style" offers three defaults: bottom bar / right column / corner. Direct keyboard shortcuts are supported (`0` `1` `p` `=` `|` …; `Esc` returns to select). The group flyout has a "pin" button: when pinned, the flyout stays after picking a brush (click the group again to close); the preference persists. On phones (≤800px) the compact bar is the default and brushes wrap to two rows; **mobile groups are reduced to 4** — Levels (edges merged in) / Clock / Bus (formerly "Data", now also contains `x`) / Other (X/Z + gap) — and **every group ends with a "." hold brush**, so the toolbar no longer needs a separate hold brush (desktop keeps 6 groups + a separate hold).
- **Right-click**: erase a cell; hold and **drag a state cell to the right** = hold (`1....` semantics).
- **Nodes and arrows**: the cell popup's "Place node" assigns an a–Z letter automatically; open the "Edges" popup from the Lanes & groups panel to connect nodes — every wavedrom arrow notation is covered, and the connections plus labels show on the editor grid in real time. The Settings menu offers the node-mark position (a 3×3 grid, default left-mid) and display scale (50%–150%). **Multiple connections between the same pair of nodes fan out automatically** — straight ones spread in parallel along the normal, curved ones increase their arc height, and labels shift along the path so nothing overlaps.
- **Groups**: nested subgroups are supported; lanes can be moved into/out of groups; a group row is a thin separator band, and the ▸ on the editor's group row folds/unfolds the whole set of signals (export follows what's visible).
- **Lane properties**: ⚙ sets period and phase — e.g. the DDR example uses CK×2 and command phase 0.5.
- **Auto mode**: start it with the "Auto" button in the toolbar or by middle-clicking a cell; it locks one cell and keeps taking states. Brush keys, clicking brushes and picking state glyphs in the panel all paint the current cell and **advance in the current direction**. **The button cycles through three states** — off ("Auto") → right ("Auto →", step one cell right, jumping to the first cell of the next visible lane at the row end) → down ("Auto ↓", step to the next visible lane, same cycle) → off. On phones the labels are the short forms: Chinese "自动" → "右移" → "下移", English "Auto" → "→" → "↓". The direction resets when you exit, and the next start is right again. Arrow keys move the selected cell. **While the state panel is open, the selection moving by any means brings the panel along** (brush keys, brush clicks, panel glyphs, arrow keys, middle-click). `Enter` toggles the panel; `Esc` closes the panel first and only exits the mode on the next press. At the end (last row end when stepping right, or the last row when stepping down) it stays on the current cell instead of exiting.
- **Label retention**: on by default in Settings. With it on, a cell with a data label keeps the label when you switch between `= 2–9` data colors; switching to `x`/`z` hides the label but stashes it while the cell stays selected, restoring it when you switch back to a data character; editing a labeled cell with the `= 2–9` brushes also keeps the label. The stash is dropped once the cell is deselected. Turning it off restores the old "changing the character clears the label" behavior.
- **Touch and narrow screens**: ≤800px switches to the mobile layout automatically (toolbar wraps, ±4 steps and the auto-mode on/off wording and its separator are hidden, spacing and padding tighten). You can also choose manually under **Settings → "View mode"**: **Auto** (decide by viewport width) or **Mobile layout** (always use the mobile version regardless of width; the preference persists). **The top bar is trimmed** to the brand (showing "Wave", with the version pill inline on the same row) and, on the right, **Settings / Import / Export** (compact plain text, no dropdown arrows). **The leftmost button in the editor toolbar is ◫**: it **shows/hides the Lanes & groups panel** — when shown, the panel is the editor's left column (a single column of small buttons: +Sig / +Clk / +Bus / +Spacer / +Grp plus the "Nodes" and "Chart" popup buttons), the brush toolbar **spans the full width below both the panel and the editor**, and the grid sits to the right; when hidden the editor is full width (the preference persists). **Live preview and WaveJSON code collapse into two buttons** (pinned to the bottom of the page) by default; tapping opens them as an overlay (switch between preview/code, ✕ or tapping again closes). The group brush flyout wraps when there are many brushes and its width is clamped to the viewport so it never runs off screen. Touch (coarse pointer) devices support **one-finger painting / holding / erasing** (the "Erase" brush can be activated as an eraser directly on touch; desktop still favors right-click), two-finger panning of the grid, and drag-to-reorder from the grip. The Signal\cycle corner cell has a toggle controlling the drag/more/delete hover buttons of the name column (hidden by default, preference persisted). The state panel is reduced to two rows — row 1 the title (current state), row 2 "data label input · place/remove node"; the state glyph grid, fill colors and the clear button are removed (change states with the bottom brush bar or the wheel). The hover action bar auto-hides while renaming. Desktop mouse behavior is unchanged.

## Structure and settings (left panel + popups)

- **Lanes & groups panel**: on desktop it is permanently the editor's left column (one button wide); on mobile it is the left column toggled by ◫. Its content is a single column of add buttons (+Sig / +Clk / +Bus / +Spacer / +Grp), the two popup buttons and "Clear". "Clear" wipes every signal back to an empty document (`Ctrl+Z` undoes it). New lanes are **pre-filled with 8 cycles** (clock `p`, signal `0`, bus `x`; the first cell gets the base state, the rest are hold characters `.`). All lane management happens in the **editor's grid row headers**: rename inline, hover the name column to reveal the ⋮⋮ drag grip and ⋯/🗑 (the ⋯ menu offers duplicate / move into group / leave group / lane properties / delete; spacer rows only offer delete). **Drag to reorder**: dropping on a row's top/bottom edge inserts before/after it, dropping in the middle of a group row moves it to the end of that group (the group row highlights); dragging a group moves it whole and it can't land inside itself; `Esc` cancels a drag and a drop counts as one undo step.
- **Name column width**: auto by default — it follows the longest name (measured precisely with canvas and the real font, for both CJK and Latin), capped at 480px, with ellipsis for overly long names and the full name visible on hover. A **draggable splitter** sits between the name column and the waveform area: drag to set the width manually (remembered), double-click to return to auto.
- **Nodes** (panel button, popup): place nodes first, then connect them here — a list of node-to-node connections (style + label); the popup scrolls internally when taller than the viewport.
- **Chart** (panel button, popup): head/foot text and tick/tock/every labels (numbers, `"start step"` strings, or custom label arrays), hscale, default/narrow skin, hbounds cropping (applies to preview and editor together); the popup scrolls internally when taller than the viewport.
- **Cycle stepper**: −4/−/＋/＋4 adjust the grid's cycle count, with a lower bound that follows the waveform content.

## View and appearance

- **Theme**: dark (logic analyzer) ⇄ light (engineering blueprint), persisted; exported SVG/PNG always use the light original palette.
- **Wave background**: Settings → Look → "Wave bg" is an N-choice option — Default (theme background) / White / Paper / Mist / Sage, each mapping to a matching tone in dark theme (pure black / warm charcoal / deep blue / ink green); persisted. The editor-screenshot export follows this setting for both the waveform area and the name column.
- **Name background**: Settings → Look → "Name bg" lets you choose "Separate" (default; the name column uses the panel color to set it apart) or "As waveform" (the name column shares the waveform background, the right-edge divider stays, hover/selection feedback is unchanged); persisted.
- **Zebra stripes**: Settings → Look → "Zebra" shows/hides the faint stripes on odd waveform rows (shown by default to help track rows horizontally; the group row's light green is a functional group color and ignores this switch). When "Name bg = As waveform" is on and zebra is shown, odd name-column rows get the same stripe, aligned row by row with the waveform; persisted. Editor-screenshot export follows these settings.
- **View**: the View menu in the top toolbar switches the preview between the right side and below the editor, and independently shows/hides the live preview and the WaveJSON code panes. Two **draggable splitters** customize the layout (preview size, name-column width; double-click resets); persisted.
- **Code display**: the WaveJSON code pane has a Relaxed mode (short objects inline, 128-column budget) and a Compact mode (lane objects on one line, skeleton line by line); persisted. Download/copy JSON, the kroki snippet, and the **VS Code extension's fence write-back** all follow the current mode (Compact no longer gets expanded to 2-space indentation on write-back).
- **Fonts**: UI and data/code fonts are chosen independently — LXGW WenKai Mono (default, loaded on demand in slices) / LXGW WenKai / IBM Plex Sans + JetBrains Mono / system fonts (system-ui, zero network dependency).
- **Trace style**: slim or glow stroke styles.

## Import and export

- **Import**: open a file (JSON, or SVG / PNG with embedded WaveJSON), drag a file onto the window, paste WaveJSON, or use the URL `#` parameter (official editor links and compressed share links both open; **the address bar no longer keeps the waveform code** after import, and editing never writes it). Lenient WaveJSON is supported — `//` comments, unquoted keys, single quotes, trailing commas (parsing matches the official editor).
- **Export**: official-rendered SVG / PNG (2×); editor screenshot SVG / PNG (2×) (rebuilt as vectors, without the toolbar, right-side empty columns or bottom empty area; colors follow the current theme, and the name column's font size and position come from the real on-screen layout so it matches what you see); JSON / copy kroki snippet / copy share link (official WaveJSON format, interoperable with the official editor) / copy compressed share link (lz-string encoded, about 60% shorter; opens in this app). Exported SVG/PNG embed WaveJSON metadata (SVG `<metadata>` / PNG `iTXt` chunk, without affecting display), read back automatically on import. **Export filenames**: with a title, `wavdrom_gui_<title>` (filesystem-illegal characters cleaned, overly long titles truncated); without a title, `wavdrom_gui_<date>_<index>` (e.g. `wavdrom_gui_260906_1`, where index counts untitled exports that day and survives reloads).
- **Undo/redo**: up to 100 steps (Ctrl+Z / Ctrl+Y), with consecutive similar small edits merged automatically.
- **Examples menu** (Import → Examples): the list is **numbered from 0** with the waveform name after the number (no more "Step N") plus an empty document; it covers every official tutorial example and 4 handy templates; auto-saved to localStorage.
