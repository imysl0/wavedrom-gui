粘贴 WaveJSON

把官方编辑器或别处的 WaveJSON 粘进来，解析后会转成可点击编辑的网格。

WaveDrom-Gui dev

单文件 HTML 应用，零构建、离线可用：鼠标点击编辑时序图，同时官方引擎实时渲染，同步生成 WaveJSON。内嵌官方 WaveDrom v3.5.0 渲染库与 default / narrow 两套皮肤。

支持深浅主题、常用wavedrom语法，以及 SVG / PNG / JSON / 分享链接导出。

仓库地址：cnb.cool/linshi-2026/wavedrom-gui
