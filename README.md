# WaveDrom 可视化编辑器

单文件 HTML 应用（约 230 KB，零依赖、离线可用）：用鼠标点击/拖拽编辑 WaveDrom 时序图，右侧实时渲染，左侧同步生成 WaveJSON 代码。

## 验收

官方教程 https://wavedrom.com/tutorial.html **Step 1–8 全部实例已通过纯鼠标操作复现验收**（13/13 项，含 hscale 1/2/3、narrow 皮肤、head/foot 刻度、两组箭头示例）：验收脚本只通过图形界面点击完成绘制，将生成的 WaveJSON 交给官方 WaveDrom 渲染器，与教程参考定义的渲染结果做 SVG 逐字节对比，全部一致。

## 使用

直接用浏览器打开 `index.html` 即可（file:// 协议可用，无需服务器）。

- **点选**：选择工具点击任意单元格，弹出状态面板（16 种波形状态 + 数据标签 + 节点标记）
- **笔刷**：选下方笔刷后点击或拖动涂抹；「数据」笔刷拖动自动拉出宽框（`=` 后自动补 `.`）；「.」笔刷延续上一拍状态（时钟后会继续走时钟）
- **右键**：清除单元格
- **节点与箭头**：单元格弹窗「放置节点」自动分配 a–Z 字母；左侧「边与箭头」面板连线，覆盖全部 wavedrom 箭头写法
- **分组**：支持嵌套子分组；通道可移入/移出分组（树形面板的悬停按钮）
- **通道属性**：通道行悬停 ⚙ 设置 period（周期）与 phase（相位），如 DDR 示例的 CK×2、命令相位 0.5
- **图表设置**：head/foot 文字与 tick/tock/every 刻度、hscale 水平缩放、default/narrow 皮肤
- **导入**：打开 JSON 文件、粘贴 WaveJSON、URL `#` 参数（与官方编辑器链接互通）
- **导出**：SVG / PNG(2×) / JSON / 复制 kroki 代码块 / 复制分享链接
- 文档自动保存到 localStorage；「示例」菜单内置 4 个常用模板 + **官方教程 Step 2–8 全部示例**（Step 1 即「入门 · 官方默认」）+ 空白文档
- **主题**：顶栏 ☀/🌙 一键切换深色（逻辑分析仪）与浅色（工程图纸）主题，偏好持久化；浅色下预览为原生黑线白底（与官方渲染一致），两种主题下的导出 SVG/PNG 均为浅色原始配色

## 技术说明

- 内嵌官方 [WaveDrom](https://wavedrom.com/) v3.5.0 渲染库与 default/narrow 两套皮肤（来源 wavedrom.com）
- 深色"逻辑分析仪"主题；在线时加载 IBM Plex Sans + JetBrains Mono，离线自动回退系统字体
- 网格编辑区的迷你波形为自绘 SVG，语义与官方渲染器一致（`p.......` 与 `p` 长度不同、尾部点号有含义、相邻数据字符各自成框等，均按官方语义实现）
- 浅色导出不受深色界面影响：导出的 SVG/PNG 为原始配色（PNG 底为白色）
